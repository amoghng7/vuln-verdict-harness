# Data, model weights and licensing notice

## What is distributed

This checkout contains project source code, documentation and aggregate results, plus the self-written tiny Java
example, its SARIF fixture with self-written demo rule metadata, and bundled tiny-example probabilities. It includes
no private evaluation repository, private dataset, model weights, generated evaluation reports, or spend logs.

## What is not distributed

- **Training and evaluation datasets**: no training, validation, test, stress, dev, or real-world JSONL datasets,
  labels, raw private Semgrep outputs, or private prediction files are included. The tiny-example JSONL probabilities
  are the sole bundled prediction fixture, not an evaluation dataset.
- **Restricted registry metadata**: `training/synth/semgrep_rules.json` is deliberately absent. The targeted generator
  needs locally supplied metadata that the user is authorized to use; see `training/synth/README.md`.
- **LoRA adapters / model weights**: fine-tuned adapters (`*.safetensors`, about 419 MB each) are not included. The
  `r2_s7` adapter remains private. The base model (`meta-models/Muse-Glimmer-30B`) is obtained separately under its
  own license.
- **Real-world evaluation repository**: its code, file names, labels, predictions, and evaluation set are private and
  are not published here.

Deleting restricted files from a branch does **not** remove their historical Git blobs. Before public distribution,
the author must purge the relevant history or replace the repository with a verified clean snapshot and inspect the
result. A current-tree deletion alone is not sufficient.

## Training-data provenance and licensing warnings

- **OWASP Benchmark (Java)**: test cases were modified (comments stripped, classes renamed to `RequestHandler`, and
  windowed) to build prompts. OWASP Benchmark is licensed under **GPL-2.0**, so any dataset containing that modified
  code is a GPL-2.0 derivative and must be redistributed under GPL-2.0 terms.
- **Semgrep rules** (`training/synth/semgrep_rules.json`, rule IDs and messages used in prompts): these came from the
  Semgrep registry and are covered by the **Semgrep Rules License v1.0**, which restricts some uses, particularly
  offering the rules in a competing hosted/SaaS product. Check that license before redistributing the rule file or
  datasets embedding rule messages.
- **Synthetic data generated with Muse Spark (Meta Model API)**: much of the training and stress data was generated by
  Meta's model. Meta's current API terms govern output use, model training, and redistribution. Review those terms
  before sharing synthetic data or anything trained on it. This repo does not include the synthetic data.

The code license in `LICENSE` does not replace or grant rights to these third-party data sources.

## Selection, independence, and result caveats

- The **dev set** has 82 alerts from six public repos and a single annotator. It influenced model and band selection.
- The **real set is not independent**. It was excluded from direct model/band selection scores, but round-1 real-set
  failure categories informed targeted synthetic training-data families. No real repository code was copied; the
  targeted design still leaks distributional information, so real-set numbers are optimistic.
- The real set has only 105 alerts from one deliberately vulnerable repository: 98 TP and **only 7 FP**, labelled by one
  reviewer. Always predicting TP scores **0.933 accuracy and 0.5 balanced accuracy**, so accuracy and FP conclusions
  are weak.
- The **stress set is synthetic** and was generated and judged by the same model family. It measures behavior on
  model-written code, not independent real-world generalization.
- Historical **83/87** remediation was Semgrep clearance under the earlier same-rule check, not a semantic-fix result
  and not reproduced under the stricter any-new-rule verifier. **Semgrep-cleared; not compiled or tested.**

See `docs/results/` for historical detailed reports and `EVAL.md` for evaluation limitations.
